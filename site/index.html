      How it works

      1. PaintEach control draws itself on a Canvas 2D scene graph. The DOM holds only a hidden accessibility outline: labels and states, no values.
      2. TypeKeystrokes pass through one hidden input that's emptied after every event, then go into a wipeable Uint32Array buffer.
      3. ValidateShared rules check the value as the person types, the same rules your server will apply.
      4. SealOn submit, password bytes are encrypted for your server's public key, bound to a one-time challenge, and wiped from memory.
      5. VerifyYour server decrypts with the bundled helper for your language, re-validates with the same rules and stores a peppered scrypt hash.

      import { PixiForm } from './PixiForm';   // thin wrapper, StrictMode-safe

export function Signup() {
  return (
    <PixiForm
      theme="indigo"
      config={{
        fields: [
          { type: 'email', name: 'email', label: 'Email', required: true },
          { type: 'phone', name: 'mobile', label: 'Mobile', defaultCountry: 'IN' },
          { type: 'date', name: 'dob', label: 'Date of birth', max: 'today' },
        ],
        onSubmit: async (values, form) => {
          const body = await form.serialize({ encryptionKey: session.encryption });
          const res = await secureSubmit('/api/register', body, { csrfToken: session.csrfToken });
          return res.json();   // { ok, message, fieldErrors }
        },
      }}
    />
  );
}

      Frequently asked questions

      What is PixiFormUI?

      PixiFormUI is a JavaScript and TypeScript form library that draws every field on an HTML canvas. Typed values live in wipeable memory instead of the page DOM, so browser extensions, session-replay tools and injected scripts can't read them.

      How does it protect passwords?

      Password fields never become JavaScript strings. On submit they are encrypted in the browser for your server's public key (ECDH P-256, HKDF-SHA256 and AES-256-GCM), bound to a single-use challenge, then wiped from memory. Decryptors are included for Node.js, Python, Go, C#, Ruby, PHP and Java.

      Is a canvas form accessible?

      Yes. A hidden accessibility outline gives screen readers headings, labelled groups, roles, states and linked error messages, and the forms follow high contrast, forced colors, reduced motion and browser zoom.

      Does it work with React, Angular or plain HTML?

      Yes. Use the <pixi-form> web component in plain HTML, the provided React and Angular wrappers, or the framework-agnostic mountPixiForm() function in Vue, Svelte or anything else.

      How big is it, and what does it depend on?

      The complete standalone bundle is about 57 KB gzipped and has no runtime dependencies. It needs no WebGL, no workers and no unsafe-eval, so it runs under a strict Content Security Policy.

      Can AI assistants fill in the forms?

      Through the included MCP server, an assistant can validate and prefill a registration with non-secret details. The person then opens a single-use link and enters the password themselves, so secrets never pass through the AI.
