Exam demo

A five-question timed quiz built with pixiformui/exam: one question per screen, a countdown, a question navigator, mark for review, and a warning before you finish with questions unanswered. The questions are drawn on a canvas, not written into this page, and the answer key stays on our server: finish to see what your server would receive and the score it sends back.

Things to try

  • Switch to another tab and back: the report counts it.
  • Mark a question for review, then jump with the numbered squares (or the arrow keys).
  • Finish with a question unanswered: you're asked once.
  • Let the timer run out: your answers are sent and the form locks.
  • Open the ⤢ button for a distraction-free view.

The code

import { mountExam } from 'pixiformui/exam';

await mountExam(host, { title: 'Space quiz', action: '/api/answers' }, {
  timeLimit: 3 * 60,
  shuffleOptions: true,
  questions: [
    { id: 'q1', text: 'Which planet is the largest?',
      options: ['Earth', 'Jupiter', 'Mars'] },
    { id: 'q5', text: 'Why do we have seasons?', answer: 'long' },
  ],
});
