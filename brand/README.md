# PixiFormUI brand assets

## The mark

A **masked form field**: a label bar, a text field with three square "pixels" (a password mask, and a nod to the
canvas they're drawn on) and a teal caret. It says "secure form" at a glance and stays legible at 16 px.

| File | Use |
| --- | --- |
| `logo.svg` | Primary lockup on light backgrounds |
| `logo-dark.svg` | Primary lockup on dark backgrounds |
| `logo-mono.svg` | One colour (`currentColor`): print, embossing, single-colour UI |
| `logo-mark.svg` | Symbol alone: favicons, avatars, app icons |
| `logo-mark-mono.svg` | Symbol in one colour (`currentColor`) |
| `favicon-32.png`, `icon-192.png`, `icon-512.png` | Raster icons (transparent corners) |
| `apple-touch-icon.png` | 180×180, full-bleed (iOS applies its own mask) |
| `og-image.png` | 1200×630 social card |

The wordmark is set in **Inter Bold** (SIL Open Font License) with −2% tracking and converted to outlines, so the
SVGs render the same everywhere. "UI" changes colour only; it's one word: **PixiFormUI**.

## Usage

- **Clear space:** keep at least a quarter of the symbol's height free on every side.
- **Minimum size:** the symbol at 16 px; the lockup at 20 px tall.
- **Don't** recolour the gradient, rotate or stretch the mark, add effects, or split "PixiForm" and "UI" with a space.
- On photos or busy backgrounds, use the mono version or put the logo on a solid panel.
